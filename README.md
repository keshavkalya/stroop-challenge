# Stroop Challenge

Stroop Challenge is a brain-training browser game based on the Stroop effect: a colour word such as RED appears in a different ink colour, and you tap the ink colour, not the word you read, which makes your prefrontal cortex hold back the automatic reading response. It has three difficulty levels, a countdown timer, streak bonuses, sounds made with the Web Audio API, a canvas neural-network background with particle effects, keyboard shortcuts (keys 1 to 6), and separate phone and laptop layouts, all built with plain HTML5, CSS3, vanilla JavaScript and GSAP for animation. To run it locally, open the folder in a terminal, start any static server (for example `python3 -m http.server 5500`) and visit http://localhost:5500; the live version is at https://stroop-challenge-nine.vercel.app.
